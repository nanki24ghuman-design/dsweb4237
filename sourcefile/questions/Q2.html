Q2. binary search.


#include <stdio.h>

int main()
{
    int a[5], i, value;
    int low, high, mid, found = 0;

    printf("Enter 5 numbers in ascending order: ");

    for(i = 0; i < 5; i++)
    {
        scanf("%d", &a[i]);
    }

    printf("Enter the value to search: ");
    scanf("%d", &value);

    low = 0;
    high = 4;

    while(low <= high)
    {
        mid = (low + high) / 2;

        if(a[mid] == value)
        {
            found = 1;
            break;
        }
        else if(value < a[mid])
        {
            high = mid - 1;
        }
        else
        {
            low = mid + 1;
        }
    }

    if(found == 1)
    {
        printf("Value found at position %d", mid + 1);
    }
    else
    {
        printf("Value not found");
    }

    return 0;
}

Output

Enter 5 numbers in ascending order: 10 20 30 40 50
Enter the value to search: 40
Value found at position 4

Complexity

Time Complexity:
Reading the input : O(n)
Binary search     : Best O(1), Worst O(log n)
(each step cuts the search area to half)

Space Complexity: O(n) for the array, O(1) extra space.
