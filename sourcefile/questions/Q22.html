Q22. Time complexity of all 21 programs

Time complexity tells how the running time grows when the input size n grows.
Space complexity tells how much memory the program needs.

Meaning of common complexities:
O(1)       constant time        (array element access)
O(log n)   logarithmic time     (binary search)
O(n)       linear time          (linear search)
O(n^2)     quadratic time       (bubble sort)

n = number of elements / nodes. For polynomials: m, n = terms of the two
polynomials, q = terms of the quotient, r = maximum terms of the remainder.
Q1 to Q13 use fixed-size arrays, but the table shows how the program scales with n.
