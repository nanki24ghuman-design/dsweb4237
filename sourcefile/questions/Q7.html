Q7. Make a stack using arrays without global variables. Use 1 for push, 2 for pop, 3 for peek, and 4 for exit. Check whether the stack is full or empty.


#include <stdio.h>

int main()
{
    int stack[5], top = -1;
    int choice, value;

    while(1)
    {
        printf("\n1. Push\n2. Pop\n3. Peek\n4. Exit\n");
        printf("Enter your choice: ");
        scanf("%d", &choice);

        if(choice == 1)
        {
            if(top == 4)
            {
                printf("Stack is full");
            }
            else
            {
                printf("Enter value: ");
                scanf("%d", &value);

                top++;
                stack[top] = value;

                printf("Value pushed");
            }
        }
        else if(choice == 2)
        {
            if(top == -1)
            {
                printf("Stack is empty");
            }
            else
            {
                printf("Deleted value: %d", stack[top]);
                top--;
            }
        }
        else if(choice == 3)
        {
            if(top == -1)
            {
                printf("Stack is empty");
            }
            else
            {
                printf("Top value: %d", stack[top]);
            }
        }
        else if(choice == 4)
        {
            break;
        }
        else
        {
            printf("Invalid choice");
        }
    }

    return 0;
}

Output

1. Push
2. Pop
3. Peek
4. Exit
Enter your choice: 1
Enter value: 10
Value pushed

Enter your choice: 1
Enter value: 20
Value pushed

Enter your choice: 3
Top value: 20

Enter your choice: 2
Deleted value: 20

Enter your choice: 4

Complexity

Time Complexity:
Push : O(1)
Pop  : O(1)
Peek : O(1)

Space Complexity: O(n) for the stack array (n = size of the stack).
