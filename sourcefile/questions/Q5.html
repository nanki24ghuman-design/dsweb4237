Q5. Write a C program for bubble sorting.


#include <stdio.h>

int main()
{
    int a[100], n, i, j, temp;

    printf("Enter the size of array: ");
    scanf("%d", &n);

    printf("Enter the array elements: ");

    for(i = 0; i < n; i++)
    {
        scanf("%d", &a[i]);
    }

    for(i = 0; i < n - 1; i++)
    {
        for(j = 0; j < n - 1 - i; j++)
        {
            if(a[j] > a[j + 1])
            {
                temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }

    printf("Sorted array: ");

    for(i = 0; i < n; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}

Output

Enter the size of array: 5
Enter the array elements: 9 6 8 5 7
Sorted array: 5 6 7 8 9

Complexity

Time Complexity:
Best = Average = Worst = O(n^2)
(this program has no early-exit check, so it always makes n(n-1)/2 comparisons)

Space Complexity: O(n) for the array, O(1) extra space (in-place sort).
