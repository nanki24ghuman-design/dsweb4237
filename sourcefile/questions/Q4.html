Q4. Enter an array and display the positive difference between adjacent numbers.


#include <stdio.h>

int main()
{
    int a[100], n, i, diff;

    printf("Enter the size of array: ");
    scanf("%d", &n);

    printf("Enter the array elements: ");

    for(i = 0; i < n; i++)
    {
        scanf("%d", &a[i]);
    }

    for(i = 0; i < n - 1; i++)
    {
        if(a[i] > a[i + 1])
        {
            diff = a[i] - a[i + 1];
        }
        else
        {
            diff = a[i + 1] - a[i];
        }

        printf("Difference between %d and %d = %d\n",
               a[i], a[i + 1], diff);
    }

    return 0;
}

Output

Enter the size of array: 4
Enter the array elements: 14 8 12 6
Difference between 14 and 8 = 6
Difference between 8 and 12 = 4
Difference between 12 and 6 = 6

Complexity

Time Complexity: O(n)  (one loop, each pair is checked once)

Space Complexity: O(n) for the array, O(1) extra space.
